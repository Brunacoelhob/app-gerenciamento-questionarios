# 📋 Sistema de Gestão e Aplicação de Questionários

> Aplicação web para criação de banco de perguntas, montagem de formulários/questionários e coleta de respostas de usuários com validações dinâmicas de regras de negócio.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma aplicação client-side desenvolvida em JavaScript, HTML5 e CSS3 integrada ao `json-server` (MOCK de API REST) para persistência de dados.

A aplicação permite que administradores criem **perguntas reutilizáveis**, as combinem em **formulários configuráveis** com status e período de vigência, e disponibilizem para pessoas responderem com validação de duplicidade por e-mail e regras estritas por tipo de questão.

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5 / Tech Clean Design System
* **Alertas & UI:** SweetAlert2 & Bootstrap Icons
* **API REST Fake / Persistência:** `json-server`
* **Gerenciador de Pacotes:** Node.js / npm
